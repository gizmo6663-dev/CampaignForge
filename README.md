# CampaignForge

CampaignForge is a lightweight D&D 5e Game Master companion app with:

- Character sheet creation and quick reference cards
- Dice roller with common dice presets and modifiers
- Ambient sound controls for session mood
- Fantasy image gallery for visual inspiration

## Run locally

Open `/home/runner/work/CampaignForge/CampaignForge/index.html` in a browser.
